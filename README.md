# GPA Calculator

A simple C++ GPA Calculator

## Features

- Takes number of courses as input
- Accepts grades and credit hours
- Calculates total credits
- Calculates GPA/CGPA
- Displays course-wise details

## Technologies Used

- C++
- File Handling (if implemented)
- Standard Template Library (STL)

## How to Run

1. Compile the code:
   g++ main.cpp -o gpa

2. Run:
   ./gpa
